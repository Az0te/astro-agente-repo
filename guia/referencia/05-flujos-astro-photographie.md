# Flujos de referencia (astro-photographie.fr) para OSC + dual band

### OSC5 — RGB (OSC) + dual band Hα-OIII (el caso del usuario)
1. Antes de procesar: alinear todos los stacks entre sí y recortar bordes negros a la misma dimensión.
2. RGB: Gradient Correction → BXT **Correct Only** → Plate Solve → SPCC → BXT (stellar + nonstellar) → SXT → estrellas RGB aparte; starless RGB → NXT.
3. HOO: Gradient Correction → BXT → SXT → NXT → HOO starless → **DBXtract** (Hα + OIII; o su emulación con PixelMath) → MAS sobre Hα y OIII por separado (GHS si se quiere afinar).
4. RGB starless → MAS. Estrellas RGB → Star Stretch.
5. Mezcla no lineal con **CombineRGBAndNarrowband** (RGB + Hα + OIII) → NXT → "Boost dynamic & colors" (curvas) → Screen Stars (star replacement) con las estrellas RGB.
### HRGB1 — Hα + RGB con estrellas RGB
RGB: Gradient Correction → Background Neutralization → BXT Correct Only → Plate Solve → SPCC → BXT → SXT. Hα: Gradient Correction → BXT → SXT → NXT → GHS. Starless RGB → NXT → GHS. "Combine Ha with RGB" → RHaGB → (LRGB opcional con Hα como L) → NXT → Boost → Screen Stars.
### OSC2 — sólo dual band
HOO → Gradient Correction → BXT → SXT → NXT → DBXtract → NXT + MAS por canal → HOO Mix (Perfect Palette Picker) → NXT → Narrowband Normalization → Boost → Screen Stars. Estrellas NB → **NB to RGB Star Combination + Star Stretch** (SETI Astro).
### Ajustes RC-Astro (EXT1)
- BXT Correct Only (pasada 1, lineal, antes de SPCC; además mejora la solución astrométrica, aunque la vista resultante pierde la WCS: copiarla de nuevo). ~~NXT "ligero" opcional antes de BXT~~: **descartado** (oct 2026), RC-Astro: ninguna reducción de ruido antes de la deconvolución. Ver `21-bxt-nxt.md`.
- BXT pasada 2: sharpen stars 0,30, adjust star halos **−0,30**, automatic PSF, sharpen nonstellar 0,50. **Contraste:** aescaffre (pixinsight-mcp) usa halos 0,00 porque los valores negativos le daban ringing visible antes de SXT, sobre todo en galaxias. Usar −0,30 sólo si hay blue bloat y comprobar anillos oscuros al 100 % alrededor de estrellas brillantes (o con el control de ringing de abajo); si aparecen, volver a 0,00.
- Rangos de partida de reflected-space (cursos básicos): BXT sharpen stars 0,25–0,35, adjust star halos −0,10 a +0,10, automatic PSF, sharpen nonstellar 0,90; NXT denoise ≤ 0,70 y detail ≤ 0,25 (a menudo menos), siempre después de la deconvolución. El nonstellar 0,90 es para datos bien muestreados o submuestreados: con drizzle 2x (sobremuestreado) mantener ~0,45–0,55 y comprobar "gusanos" al 100 %.
- Orden: RC-Astro desaconseja **cualquier** reducción de ruido antes de la deconvolución (el ruido fino es información que BXT usa). Nada de NXT antes de BXT completo.
- NXT ligero opcional después de BXT completo y antes de SXT (denoise 0,50). SXT con Generate star image + Large overlap, unscreen off en lineal.
- NXT "full" tras SXT (starless lineal): intensity/color separation + frequency separation, HF intensity 0,80, HF color 0,80, LF intensity 0,80, LF color 0,80, HF/LF scale 5, iterations 5.
- Alternativa de aescaffre para NXT: **varias pasadas suaves** mejor que una fuerte (denoise 0,20–0,25, detail 0,15 en lineal antes de SXT, tras estirar la L y tras estirar la RGB; 0,15 final tras LHE/HDRMT). Una pasada fuerte da aspecto de cera/plástico, pierde estrellas débiles y emborrona color. Elegir la estrategia comparando a 100 %.
- GHS → NXT final igual que el anterior.
### Sustracción de continuo (Photometric Continuum Subtraction)
Versión completa SHO: S,H,O combinados → Gradient → BXT Correct Only → Plate Solve → SPCC narrowband → extraer S,H,O → SXT + NXT por canal; RGB → Gradient → BXT Correct Only → Plate Solve (coordenadas copiadas) → SPCC → SXT → extraer R y G (con estrellas y sin estrellas). PCS con Max stars 1000, Max peak 0,80, Generate starless: SII y Hα con R, OIII con G → S,H,O continuum subtracted (lineal). Versión Hα simplificada: narrowband = Hα, broadband = R. Teoría: k = mediana robusta de (N−B_N)/(C−B_C) en estrellas no saturadas; buena k = residuos simétricos; k baja deja estrellas positivas; k alta, agujeros negros. Para OIII usar sólo G como continuo (B lleva Hβ). En IC63 v3: Ha_sub = Hα − 0,293·R − 0,00155; deja un disco oscuro donde domina el continuo de γ Cas (cubrir con la estrella o enmascarar).
### DBXtract (dual band OSC) y su emulación con PixelMath
Modelo (Raúl Hussein, documentación oficial en dbxtract.astrocitas.com): `C = A·L + P`, con C = (R,G,B) lineal, L = (SII, Hα, OIII, Hβ) y P = pedestal de fondo de cada canal (estimado por la moda). Los coeficientes de A son la QE del sensor en cada raya (× transmisión del filtro). Requisitos: lineal, sin estirar, **sin SCNR, sin SPCC ni balance de blancos** (el modelo usa la respuesta bruta del sensor), canales sin saturar, perfil de cámara correcto y flats con 'Separate CFA flat scaling factors' (conserva la escala relativa de cada canal).
- QE del IMX571 (nuestra ASI2600MC) según la tabla de DBXtract: Hα 656 nm → R 0,80 / G 0,11 / B 0,04; OIII 501 nm → R 0,04 / G 0,93 / B 0,50; SII 672 nm → R 0,74 / G 0,13 / B 0,05; Hβ 486 nm → R 0,01 / G 0,67 / B 0,70. El Antlia Hα/OIII 5 nm no deja pasar Hβ ni SII.
- **Emulación para el Antlia HO** (el script no se puede lanzar desde el watcher): restar a cada canal su fondo (mediana/moda de cielo limpio tras corregir el gradiente) y resolver por mínimos cuadrados las 3 ecuaciones con 2 incógnitas (sistema bien condicionado, número de condición 1,4). Con R, G, B ya sin pedestal (`$T[0]`, `$T[1]`, `$T[2]` en PixelMath):
  - `Ha = 1.2563*R - 0.0293*G - 0.0460*B`
  - `OIII = -0.1378*R + 0.8370*G + 0.4542*B`
  - Variante ponderando G ×2 (doble de píxeles verdes en la matriz Bayer, menos ruido): `Ha = 1.2565*R - 0.0330*G - 0.0391*B`; `OIII = -0.1425*R + 0.9430*G + 0.2574*B`.
  - Recortar a ≥ 0 sólo al final y vigilar sobre-restas (zonas negras) en señal débil. Comparar con el resultado de DBXtract si el usuario lo lanza.
  - Comprobación: en una zona dominada por Hα, (G−pG)/(R−pR) ≈ 0,14 y (B−pB)/(R−pR) ≈ 0,05. Si se aparta mucho, el balance de canales no es el bruto (SPCC, flats) o hay continuo. El Hα resultante es casi 1,26·R; el que más cambia es el OIII.
  - Limitación: el modelo supone sólo rayas. El continuo que entra por las bandas de 5 nm (estrellas, nebulosa de reflexión, galaxias) también se reparte como "Hα" y "OIII": restar después el continuo con la RGB (sustracción de continuo) y, en objetos de reflexión como IC 63, no interpretar ese "OIII" como emisión.
- Combinación de varios masters de la misma raya (HO + SO + SHb, o dual band OSC + mono): Adaptive with scaling (normalizar cada uno por media y sigma y combinar en escala común; cuando difieren fondo, exposición o calibración), SNR-weighted average, Average, Minimum (rechaza gradientes y ruido residual) y Maximum (realza lo que sólo está en uno).
- La fórmula de color por defecto de DBXtract reconstruye el RGB a partir de las rayas con los mismos coeficientes de QE (color "natural" del sensor); se puede editar para HOO/SHO.
